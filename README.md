OmniPatch supports ChatGPT, Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI Assistant. We continuously work to add support for new platforms.

### How often is OmniPatch updated?

We aim to release updates within 1-2 weeks after major changes to supported applications to maintain compatibility and unlock new features.

### Do I need an internet connection to use OmniPatch?

The patching process itself requires an internet connection to validate and modify the necessary files. Once patched, some features may work offline depending on the target application.

### Will using OmniPatch affect my existing account or data?

OmniPatch operates at the application level and does not alter your account data or login credentials. It simply enables premium features in the client software.

### Can I revert the changes made by OmniPatch?

Yes, OmniPatch typically creates backup files before patching. You can use the 'Restore' function within the tool or reinstall the target application to revert changes.

### Why does the extraction password need to be 'omnipatch'?

The password protects the archive from being automatically scanned or blocked by security software. It is a standard practice for tools that modify application behavior.
